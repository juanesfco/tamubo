# AutoIA special functions (`0.14.0.dev3`)

This checkpoint adds the real error function and normal-distribution functions
before Step 4 broadens general NumPy semantics.

## Public functions

```python
from autoia import (
    erf,
    standard_normal_pdf,
    standard_normal_cdf,
    normal_pdf,
    normal_cdf,
)
```

`math.erf(validated_x)` and a module-level `from math import erf` alias are also
handled by AutoIA's local non-mutating dispatch.  NumPy does not provide a
portable top-level `np.erf`, so the public `autoia.erf` helper is the preferred
array-independent spelling.  `scipy.special.erf` and `scipy.stats.norm` are not
yet automatically traced.

## Trusted error-function kernel

For moderate positive `x`, AutoIA uses

\[
\operatorname{erf}(x)
=\frac{2}{\sqrt\pi}
\sum_{n=0}^{\infty}
(-1)^n\frac{x^{2n+1}}{n!(2n+1)}.
\]

Once `n+1 >= x^2`, subsequent exact term magnitudes decrease, so the first
omitted term rigorously bounds the alternating tail.  Negative arguments use
odd symmetry.

For large positive `x`, AutoIA evaluates `erfc(x)=1-erf(x)` using repeated
integration by parts on

\[
I(x)=\int_x^\infty e^{-t^2}\,dt.
\]

Two consecutive asymptotic partial sums rigorously bracket `I(x)` because the
remaining integral is positive and has known sign.  This avoids trusting the
platform `math.erf` or `math.erfc` implementation.

## Standard normal functions

The standard-normal density and CDF are

\[
\phi(x)=\frac{e^{-x^2/2}}{\sqrt{2\pi}},
\qquad
\Phi(x)=\frac12\left[1+\operatorname{erf}\left(\frac{x}{\sqrt2}\right)\right].
\]

All appearances of `pi` and `sqrt(2)` are rigorous intervals generated by the
trusted kernel.  They are not ordinary rounded constants silently treated as
exact mathematical constants.

## Dependency-preserving polynomial lifting

For `erf`, normalized Taylor coefficients

\[
a_n(c)=\frac{\operatorname{erf}^{(n)}(c)}{n!}
\]

are generated from

\[
f''(x)+2x f'(x)=0,
\]

which gives

\[
(n+2)(n+1)a_{n+2}
+2c(n+1)a_{n+1}
+2n a_n=0.
\]

The starting coefficients are a rigorous enclosure of `erf(c)` and

\[
a_1=\frac{2}{\sqrt\pi}e^{-c^2}.
\]

For the standard-normal PDF, `phi'(x)+x phi(x)=0`, giving

\[
(n+1)b_{n+1}+c b_n+b_{n-1}=0,
\]

with `b_n=phi^(n)(c)/n!`.  For the CDF, `Phi'=phi`, so

\[
\frac{\Phi^{(n)}(c)}{n!}=\frac{b_{n-1}}{n},\qquad n\ge1.
\]

The same recurrences are interval-evaluated over the whole certified argument
range to bound the Taylor remainder.  Hence all three functions remain
polynomial-plus-remainder objects rather than collapsing immediately to boxes.

## General normal distribution helpers

For finite constant `mean=mu` and strictly positive finite constant `std=sigma`,

\[
z=\frac{x-\mu}{\sigma},
\]

and AutoIA defines

\[
f_X(x)=\frac{\phi(z)}{\sigma},
\qquad
F_X(x)=\Phi(z).
\]

Current `normal_pdf`/`normal_cdf` support requires `mu` and `sigma` to be
constant real scalars.  Uncertain distribution parameters are deferred.
